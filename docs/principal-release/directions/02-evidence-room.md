# Direction 02 — Evidence room

Grounding: the advanced branch's approved evidence, source hashes and agent-review records; desktop/mobile baseline inspected on Vercel.

A document queue occupies the first screen. Selecting a claim reveals its source, missing facts, and proposed owner action in a split reading pane. Progress means evidence resolved, not tasks checked. Strong for audit and adviser collaboration, but financial consequences would be a secondary view. Rejected as the entry point because this owner needs a portfolio decision before a document workflow.
